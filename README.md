# OIC-293

The goal of this project is to quantify the number of senescent cells which have been stained using a beta-galactosidase in an x-gal assay.

This is a project with Rahma Benhassoun (Rothbart Lab).

## Getting started

### Prerequisites

- [Python](https://www.python.org/downloads/) version 3.13.0

### Installation

1. Download or clone the GitHub repository
   ```bash
   git clone git@github.com:vaioic/OIC-318.git
   cd OIC-318
   ```

2. Create a python virtual environment
   ```bash
   python -m venv venv
   ```

3. Activate the virtual environment
   ```bash
   .\venv\Scripts\activate
   ```

4. Install the dependencies using Pip
   ```bash
   python -m pip install -r .\requirements.txt
   ```

### Running the code

1. Start the virtual environment if not already loaded
   ```bash
   .\venv\Scripts\activate
   ```
